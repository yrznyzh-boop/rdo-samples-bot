# بوت إعلانات تيليجرام — النسخة المعدّلة

## الملفات
- `bot_with_buttons.py`: البرنامج المعدّل.
- `bot_with_buttons.py.bak`: نسخة احتياطية مطابقة للملف الأصلي المرفوع.
- `requirements.txt`: المتطلبات.
- `config.example.yaml`: مثال إعدادات فقط، دون أي توكن حقيقي.

## ما تم تغييره
- تمت إضافة الإعلان الثاني مع الإيموجي المخصص بالمعرّف `5341633328338451873`.
- أضيف زر «قوانين» أسفل الإعلان الثاني، ويرتبط بـ `https://t.me/rdranews/20`.
- أضيفت جدولة مستقلة للإعلان الثاني كل `10800` ثانية، مع أول إرسال بعد 3 ساعات.
- أضيف الأمر `/send2`، ويقتصر على مشرفي القروب المحدد بعد التحقق من عضويتهم عبر Telegram API.
- لم يُعدّل نص الإعلان الأول أو تنسيقه، ولم تتغير آلية `/send` أو الجدولة الحالية.

## التشغيل / التحديث
1. احتفظ بنسخة من ملفات المشروع الحالي على الاستضافة.
2. ارفع `bot_with_buttons.py` إلى مجلد المشروع واستبدل الملف القديم بعد أخذ نسخة احتياطية.
3. لا تستبدل `config.yaml` الموجود لديك؛ حافظ على `BOT_TOKEN` و`GROUP_ID` والإعدادات الحالية.
4. ثبّت المتطلبات في بيئة المشروع: `pip install -r requirements.txt`
5. أعد تشغيل خدمة البوت بالطريقة المعتادة على استضافتك.

يجب أن يكون البوت مشرفًا في القروب ولديه صلاحية إرسال الرسائل. للتحقق من صلاحيات المستخدمين، يجب أن يكون البوت قادرًا على استدعاء `getChatMember` وفق إعدادات القروب.

## ملاحظات
- الجدولة الأولى تستخدم `interval_seconds` كما في الإعداد الحالي (3600 ثانية افتراضيًا).
- كل جدولة تبدأ بعد انقضاء فترتها من تشغيل البوت، ولا ترسل فور بدء التشغيل.
- لم تُضمّن أي بيانات سرية أو ملفات استضافة غير مرفقة.
